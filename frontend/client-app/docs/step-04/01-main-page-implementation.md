# Крок 4.1: Реалізація головного екрану (Головна Карта)

На цьому етапі ми створимо основний інтерфейс пасажирського додатку: інтерактивну карту з відображенням поточного місцезнаходження, автомобілів водіїв поруч та панеллю вибору напрямку поїздки.

---

## 1. Встановлення залежностей для карт та геолокації

Для роботи з картами та визначення позиції користувача нам знадобляться наступні бібліотеки:

```bash
npx expo install react-native-maps expo-location
```

> [!IMPORTANT]
> Для роботи Google Maps на Android/iOS вам знадобиться **Google Maps API Key**. Для тестування в Expo Go на початкових етапах можна використовувати стандартні карти Apple (iOS) або Google (Android), але для повноцінного функціоналу (наприклад, кастомні стилі карт) ключ обов'язковий.

---

## 2. Налаштування дозволів (Permissions)

У `app.json` додайте конфігурацію для отримання доступу до геолокації:

```json
{
  "expo": {
    "ios": {
      "infoPlist": {
        "NSLocationWhenInUseUsageDescription": "Додатку потрібен доступ до вашої локації, щоб знайти найближче вільне таксі."
      }
    },
    "android": {
      "permissions": ["ACCESS_COARSE_LOCATION", "ACCESS_FINE_LOCATION"]
    }
  }
}
```

---

## 3. Створення компонента карти (PassengerMap)

Рекомендується винести логіку карти в окремий компонент `src/components/map/PassengerMap.tsx`, щоб головний екран був чистішим.

Ключові елементи:

- `MapView` — основна область карти.
- `Marker` — кастомний маркер вашої позиції та автомобілів водіїв.
- `useRideStore` — для оновлення поточного місцезнаходження (pickupLocation) у глобальному стані.

---

## 4. Верстка головного екрану (app/(app)/index.tsx)

Згідно з дизайном (див. скріншот), екран складається з трьох рівнів:

1.  **Bottom Layer (Карта)**: Займає весь екран.
2.  **Floating UI (Меню та GPS)**:
    - Кнопка «гамбургер» меню (зверху зліва).
    - Кнопка «Повернутись до моєї локації» (знизу справа, над панеллю).
3.  **Top Layer (Панель пошуку)**: Розташована внизу екрану.

### Структура панелі пошуку:

- **Основне поле (Input замінник)**: Велика кнопка «Куди поїдемо?», яка відкриватиме екран пошуку адрес.
- **Кнопка «Запланувати»**: Для відкладених поїздок.
- **Швидкі адреси**: Кнопки «Дім» та «Робота» для швидкого замовлення в один клік.

---

## 5. Інтеграція з Zustand

На етапі ініціалізації карти (через `useEffect` та `expo-location`):

1.  Запитайте дозвіл на отримання локації.
2.  Отримайте поточні координати.
3.  Викличте `setPickup({ latitude, longitude, address: 'Поточне місце' })` у сторі `useRideStore`.
4.  Сцентруйте карту на цих координатах.

---

## 6. Візуальний стиль (Premium Look)

- Використовуйте `BoxShadow` (на iOS) або `elevation` (на Android) для карток швидких адрес та панелі пошуку, щоб створити ефект глибини.
- Додайте закруглення кутів (напр. `borderRadius: 16`) для всіх кнопок.
- Для іконок автомобілів водіїв використовуйте реальні PNG-зображення (вид зверху), щоб надати додатку завершеного вигляду.
